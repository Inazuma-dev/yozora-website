03 FUTURE PLAN

Six months to a
public beta.

A realistic progression from prototype to a usable first beta — aiming for stable foundations before broad public exposure.

MONTH 01 FOUNDATION

Core UI and browser shell

  • Stabilize responsive layout and browser chrome
  • Finalize topbar, tabs, and browser controls
  • Build first mock of “Ask this page” flow
  • Lock technical constraints for iOS 15–16
MONTH 02 STORAGE

Tabs, bookmarks, and history

  • Persist user state locally
  • Support bookmark creation and tab switching
  • Keep page context organized for future AI tools
  • Define resilience for early usage patterns
MONTH 03 AI CORE

First real AI integration

  • Extract page content from active browsing context
  • Send clean prompts to an AI service
  • Surface answers inside the browser UI
  • Evaluate model latency and cost
MONTH 04 UX

Polish and quality loop

  • Onboarding, empty states, and flow clarity
  • Improve accessibility and keyboard support
  • Refine response handling and error states
  • Reduce friction across the first-run experience
MONTH 05 QA

Internal beta and testing

  • Run focused user tests
  • Close high-priority bugs before release
  • Review privacy and data handling decisions
  • Prepare beta distribution and feedback channels
MONTH 06 PUBLIC BETA

Launch and stabilize

  • Public beta launch for early adopters
  • Track crashes, usage, and feedback loops
  • Fix regressions through a rapid hotfix cycle
  • Shape the next roadmap from real-world input
